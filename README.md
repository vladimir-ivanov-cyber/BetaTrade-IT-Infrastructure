
# BetaTrade – Modernisierung der IT-Infrastruktur

## Projektübersicht
Dokumentiertes IT-Infrastrukturprojekt im Rahmen der IT-SecurityPro-Weiterbildung, Februar–März 2026.

## Technische Schwerpunkte
- Netzwerksegmentierung mit VLANs und Inter-VLAN-Routing
- DHCP, DNS, OSPF und VoIP
- Windows Server, Active Directory und Gruppenrichtlinien
- VPN und Firewall mit OpenVPN und pfSense
- Docker und SQL
- Cloud-Backup und Disaster Recovery
- IT-Security mit OpenVAS, Suricata und ELK-Stack

## Projektdokumentation
Die für die öffentliche Veröffentlichung aufbereitete Projektdokumentation ist in diesem Repository verfügbar.
